# Model performance benchmark visualizer

User can upload any number (or all) benchmarks in the JSON format(s) available. The user can toggle select any number of them to be displayed/graphed. The selected benchmarks gets displayed on respective graphs/charts. Unselecting dynamically removes them from visualization. The processor name is included in the graph legends and axis along with the device and variant.

## Metrics Highlight Categories

- Best Accuracy
- Lowest Latency
- Fastest overall
- Best Accuracy/Latency ratio
- Higher throughput
- Number of runs

## Comparison Table

- Variant
- Device
- Processor Name
- Accuracy
- Avg Latency
- Total Time
- Throughput
- Image

## Processor abreviation

Due to space constraints with many runs, abreviate out the manufacturer name from the processor name (e.g., "Intel N97" can just be "N97" in the graphs and "Apple M1 Pro" can be "M1 Pro")
